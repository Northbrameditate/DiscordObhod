>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует WinDivert как инструмент повышенного риска или хакерскую утилиту. В результате файл удаляется и попадает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения либо выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений лучше добавить исключение; если вы не полностью понимаете последствия, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS):
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите его URL. Например, `https://dns.google/dns-query`; Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Получите zip- или rar-архив с [последнего релиза](https://github.com/Northbrameditate/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот шаг можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл:
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для добавления стратегии в автозапуск выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для себя**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — узнать состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  После изменения параметра **нужно перезапустить стратегию**.  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Опция полезна при диагностике ресурсов, которые открываются без zapret, но не работают с ним.  
  В скобках отображается режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сравнивается со списком
    - `any` — под фильтр попадает любой IP
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts-файл <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`.
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач. Если этого не произошло, обратитесь к [#522](https://github.com/Northbrameditate/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит

1. Откройте командную строку от имени администратора.
2. Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts-файл устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в появившейся папке текстовым редактором, запущенным от имени администратора;
- добавьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки;
- сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Northbrameditate/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Стратегия иногда действует некоторое время, а затем перестаёт работать после обнаружения.
> В этом репозитории есть разные стратегии обхода. Если готовые варианты не помогают, создайте новую на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте, нет ли ошибок.
- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP.
- Проверьте другие варианты стратегий, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- См. [#765](https://github.com/Northbrameditate/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Откройте `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; устраните найденные ошибки и в конце ответьте `Y`.
- Удалите каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/Northbrameditate/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`.
- Нажмите по архиву правой кнопкой, откройте свойства и, если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service`.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в Windows: нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/Northbrameditate/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузерная версия тоже недоступна, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Northbrameditate/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Northbrameditate/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что `ipset any` может нарушить открытие множества сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Northbrameditate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [в issue](https://github.com/Northbrameditate/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Добавлять адреса для обхода можно в следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
